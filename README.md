# Sing Trace

在浏览器里练唱的小工具。打开一首歌，它会在本地把人声分离出来，画出波形，并在同一条时间上叠上音高曲线，用来看颤音和音高起伏。

在线使用：<https://zekeriri.github.io/sing-trace/>

音频不会上传。分离、音高和颤音都在你的浏览器里完成。

## 使用

- 打开音频，或把文件拖进页面。支持 mp3、wav、flac、ogg、m4a。
- 也可以先点「载入示例」，听一段写好的人声加伴奏。
- 上方是提取后人声的波形，下方是音高。绿色靠近最近的音，琥珀色和珊瑚色表示偏高或偏低。紫色范围是检出的颤音。
- 拖动波形可以平移，滚轮可以缩放，拖动最下方的总览可以定位。点击波形会跳转播放。
- 「人声 / 原声」用来对比试听。空格播放，左右方向键移动，按住 Shift 平移窗口。

单声道没有声像信息，只能减弱打击乐，人声和乐器仍会叠在一起。人声明显偏离中央、或和声很重的混音，分离也会留下伴奏。

## 本地打开

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。不要直接用文件协议打开，分析线程需要模块地址。

```bash
npm test
```

测试覆盖频谱重建、纯音音高、以及立体声混音里的人声分离和颤音估计。
