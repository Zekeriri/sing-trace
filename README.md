# Sing Trace

在浏览器里看人声音高的小工具。打开一段已经提取好的人声，它会在本地画出音高线，用来看音高怎么走、哪里偏了。

在线使用：<https://zekeriri.github.io/sing-trace/>

音频不会上传。音高分析在你的浏览器里完成。

## 使用

- 打开人声，或把文件拖进页面。支持 mp3、wav、flac、ogg、m4a。
- 页面会先载入仓库里的示例：`秒針を噛む feat.尤里 - 人声.mp3`。
- 音高线按离最近音的距离着色：绿色在 ±18 音分以内，琥珀色略偏，珊瑚色偏得更多。紫色是检出的颤音。
- 拖动音高线可以平移，滚轮可以缩放，拖动最下方的总览可以定位。点击音高线会跳转播放。
- 空格播放，左右方向键移动，按住 Shift 平移窗口。

请上传人声，不要上传带伴奏的整曲。伴奏会让音高线跳来跳去。

## 本地打开

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。不要直接用文件协议打开，分析线程需要模块地址。

```bash
npm test
```

测试覆盖频谱重建、纯音音高、谐波基频，以及带颤音的音高估计。
